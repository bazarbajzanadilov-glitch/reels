# Shorts Factory

Создание роликов 9:16 и 16:9: сценарий, голос, изображения, анимация, обложка и тексты для соцсетей. Платная генерация использует Pollinations. Цены в форме предварительные; окончательное списание определяет провайдер.

## Локальный запуск

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock
.venv/bin/python server.py
```

В `.env` задаётся `POLLINATIONS_KEY`. Для генерации ключу нужны права генерации и работы с ограниченными ключами/расходами. Сайт: `http://127.0.0.1:8000`. Сервер автоматически запускает отдельный обработчик очереди; перезапуск сайта не прерывает его. Одновременно обрабатывается один ролик. Отключение компьютера останавливает обработку; после следующего запуска безопасные этапы восстанавливаются из кэша. Запрос с неизвестным платным результатом требует проверки, автоматически повторно не отправляется.

## Работа

По умолчанию сначала создаётся сценарий. Его можно проверить и изменить по сценам: текст озвучки, изображение, движение и подпись. Кнопка сборки запускает создание материалов. Сценарий тоже использует платную модель; сохранение правок бесплатно. Изменённые материалы создаются заново, совпавшие берутся из проверенного кэша.

История поддерживает поиск, фильтры, отмену, корзину и восстановление. Готовые материалы: `video.mp4`, `cover.jpg`, `script.json`, тексты соцсетей и `result.zip` в `jobs/<id>/`.

## Субтитры

Режимы: выключены, один цвет, смена цвета всего двухстрочного блока при появлении следующего. Настраиваются палитра, размер, положение, ширина, плотность, межстрочный интервал, обводка, фон и регистр. Контрастная обводка сохраняется всегда. Оформления можно сохранять в браузере. Бесплатный предпросмотр использует отрисовщик видео.

Экспорт: SRT (текст и время) и ASS (цвет, положение и обводка). Внешние проигрыватели могут иначе отображать шрифты и интервалы ASS. Встроенные субтитры отображаются одинаково в готовом видео.

Синхронизация по фразам распределяет текст внутри длительности озвучки. Дополнительная синхронизация по словам работает локально через Whisper:

```sh
.venv/bin/pip install -r requirements-align.txt
```

`requirements-align.lock` фиксирует проверенное окружение этого Mac; для другой платформы используется отдельный подбор совместимых пакетов. Первая загрузка модели `base` требует интернета, модель хранится в `.models/`. На этом Mac модель уже установлена. При слабом совпадении распознавания и сценария процесс просит выбрать фразы или исправить SRT. Пользовательский SRT можно редактировать перед перемонтажом.

Бесплатный перемонтаж меняет субтитры на сохранённых исходных материалах и блокирует обращения к генератору. Если исходников нет (например, у старого ролика), потребуется обычная сборка. Существующие готовые видео автоматически не изменяются.

## Надёжность и данные

Очередь и журнал запросов: SQLite WAL `jobs/.factory.sqlite3`. `job.json` — переносимые копии записей; вручную их менять при работающем приложении не следует. При первом запуске старая история импортируется, исходные JSON сохраняются в `jobs/.legacy-json.zip`. Некорректные записи изолируются.

У каждого ролика свой ограниченный ключ в закрытом `jobs/.private/`; он повторно используется при продолжении задачи. Ключи не передаются браузеру и не попадают в ZIP результата. Неопределённый результат создания ключа или платного запроса блокирует автоматическое повторное списание. Внешний провайдер может учитывать расходы с задержкой; лимит не заменяет его биллинг.

Файлы сохраняются атомарно, повреждённый кэш проверяется, завершённые части рендера повторно используются. Поддерживаются ограничения параллельности `NET_TTS`, `NET_IMAGES`, `NET_VIDEO`, `RENDER_WORKERS`. Фактические время, CPU и память сохраняются в метаданных задачи; скорость зависит от устройства и модели.

## Резервная копия и обслуживание

```sh
.venv/bin/python manage.py backup
.venv/bin/python manage.py restore backups/ИМЯ.zip /новая/папка
.venv/bin/python manage.py cleanup --days 30
.venv/bin/python manage.py cleanup --days 30 --apply
.venv/bin/python manage.py restore-cache .trash-cache/ИМЯ
```

Backup включает исходники, настройки, историю, результаты и кэш, с согласованным снимком SQLite и SHA-256. Архив содержит `.env` и закрытые ключи: хранить локально, не публиковать. Файл создаётся с правами 600. Восстановление возможно только в новую папку, после проверки состава и хешей. Зависимости и локальная модель скачиваются отдельно. Очистка по умолчанию только показывает объём; `--apply` переносит старый кэш в обратимую корзину и запрещена при активной очереди.

## Сервер и HTTPS

В `.env` также нужен `ACCESS_PASSWORD`. `docker compose up -d --build` поднимает отдельные web и worker. Порт доступен только через `127.0.0.1:8000`. Для публичного доступа нужны домен, DNS на сервер и `DOMAIN` в `.env`:

```sh
docker compose -f docker-compose.yml -f deploy/compose.https.yml up -d --build
```

Caddy обслуживает HTTPS. Публикация на внешнем сервере в этой работе не выполнялась. Для локального Whisper в Docker нужен build-аргумент `WITH_ALIGNMENT=1`; модель загружается в контейнер. Для её сохранения между пересборками нужен отдельный том `.models`.

## Проверки

```sh
.venv/bin/python tests/run.py
```

61 автономный тест: очередь, изоляция ключей, неопределённые ответы, отмена, восстановление этапов, редактирование, субтитры, реальный локальный перемонтаж MP4 и резервные копии. Тестовый запуск блокирует случайные внешние HTTP-запросы. Полная платная генерация после изменений не запускалась.

Адаптив рассчитан на 220–7680 CSS-пикселей. Браузерная проверка всех 1493 ширин с шагом 5: раскрытая форма и редактор сценария в обе стороны, окно субтитров и окно видео — всего 8958 проверок без горизонтального переполнения. Это проверка геометрии, а не замена физическим телефонам и телевизорам. Помощник повторного аудита: `tests/responsive-audit.js`.


## Подготовка релиза и скорость

Инструкция для VPS: [docs/DEPLOY.md](docs/DEPLOY.md). Команды `.venv/bin/python deploy.py check` и `.venv/bin/python deploy.py package` работают без обращений к генератору; архив релиза содержит только исходники и пример настроек.

Рендер повторно использует неизменяемые маски/заливки внутри процесса, не создаёт генератор тряски для неподвижной камеры и ищет текущий блок субтитров по отсортированному времени. Качество кодирования сохранено. CPU-квота и память Linux/cgroup v2 ограничивают число процессов, включая потоки кодировщика.

Бесплатный синтетический замер на этом Mac: 4 сцены по 30 кадров, 1080×1920. Медиана времени отдельного куска до изменений 1.203 с, после 1.145 с (около 5% быстрее). Декодированные кадры всех четырёх сравнений побайтно совпали; это не замер полной платной генерации и не прогноз времени API. Повторяемый помощник — `tests/benchmark_render.py`, принимает путь к прежней версии `render.py` и флаг `--full-hd`. Всего после серверных изменений проходят 65 автономных тестов.
